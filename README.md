# DecodeLabs Internship 2026 — Project 1

## Project Overview

This is a responsive landing page built for DecodeLabs as part of the Full Stack Development Internship program. The page presents the company's internship tracks, training courses, and company information in a clean, accessible layout.

## Technologies Used

HTML5, CSS3, JavaScript

## Code Structure

### HTML (index.html)
The page is built with semantic HTML5 elements. It includes a header with navigation, a hero section with key statistics, an about section, a tracks section listing internship domains, a hidden emerging tech section that appears on button click, a courses section with pricing, a contact section with social links, and a footer.

### CSS (style.css)
The styling uses custom properties for colors, follows a mobile-first approach with media queries for tablet and desktop breakpoints, and uses Flexbox and Grid for layout. The color palette includes Mocha Mousse (#A5956F) for primary elements, Ethereal Blue (#A0D4E0) for secondary accents, and Moonlit Grey (#F2F0EA) for the background.

### JavaScript (script.js)
The script handles two main interactions:
1. A toggle function for the "View All Programs" button that shows or hides the Emerging Tech section and changes the button text.
2. Smooth scrolling for all navigation links that point to sections on the same page.

## Features

- Responsive layout that works on mobile, tablet, and desktop
- View All Programs toggle button for Emerging Tech section
- Smooth scrolling navigation
- Contact section with Instagram, LinkedIn, and Email links
- Course cards with original and discounted pricing
